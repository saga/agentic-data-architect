## 修复「调查配置」弹窗（web/src）

现象：弹窗内容被截断、滚不动；左侧 5 个子页面点不动（看起来像没切换）。

根因：antd 已升到 v6，`web/src/styles.css` 里的 Tabs 布局选择器还是 v5 的类名。
v6 结构是 `.ant-tabs-nav` / `.ant-tabs-body-holder` / `.ant-tabs-body` / `.ant-tabs-content`；
v5 的 `.ant-tabs-content-holder` / `.ant-tabs-tabpane` 已经不存在。
其中 `.ant-tabs-content` 在 v6 里是**每个子页面本身**，所以老 CSS 的
`.settings-tabs .ant-tabs-content { display: flex }` 把所有已挂载的子页面都显示出来，
覆盖了 antd 的 `.ant-tabs-content-hidden { display: none }` —— 于是切换“失灵”、内容被撑长后裁掉。

改法：
- `styles.css`：选择器换成 v6 类名；用 `:not(.ant-tabs-content-hidden)` 限定只有当前页占满高度，
  并显式 `.ant-tabs-content.ant-tabs-content-hidden { display: none }`；`.settings-page` 保持
  `overflow-y: auto` 作为唯一滚动容器。
- `App.tsx`：Tabs 的 `tabPosition="left"` → `tabPlacement="start"`（v6 已弃用前者）。
- 顺带修两个既有类型错误：Modal 的 `styles.content` → `styles.container`（v6 语义键改名，
  `.ant-modal-content` 里的 `.ant-modal-container` 才是 header/body/footer 的父节点）；
  `setWorkflowTarget(null)` → `undefined`。

验证：headless Chrome + CDP 驱动（脚本在 /tmp/ada-verify/），23/23 断言通过 ——
5 个页签逐个切换都只有 1 个子页面可见、标题正确、body 无裁切、`overflow-y: auto`；
滚轮实测 `scrollTop 0 → 667`。`tsc --noEmit`（root + web）现在都是干净的。

## 待办 / 注意
